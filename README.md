# 100 Days, 100 Questions 🚀

A personal Python coding challenge where I solve **100 programming questions in 100 days** to improve my problem-solving, logic, and Python skills.

## 🎯 Goal

* Solve 1 programming question every day
* Improve problem-solving and logical thinking
* Strengthen Python fundamentals
* Build consistency through daily practice
* Track my progress publicly on GitHub

## 🔥 Challenge Rules

1. Solve at least one question every day.
2. Try to understand the logic before looking for solutions.
3. Write and test the solution myself.
4. Keep each day's solution organized in its own file.
5. Continue even when a question is difficult.

## 📈 Why I'm Doing This

This challenge is about **consistency rather than perfection**.

The goal is to become better at breaking problems down, thinking logically, debugging errors, and writing cleaner Python code one question at a time.
